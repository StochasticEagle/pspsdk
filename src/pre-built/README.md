# Versioned pre-built PRXs

The PRXs in this directory are intentional binary inputs to the release build.
They are not generated by the CMake project because this repository does not
currently contain complete, verified source-and-build recipes for them.

The release build copies only the explicitly enumerated files from the root
`CMakeLists.txt`. It does not glob this directory. Replacing one of these
binaries therefore requires an intentional repository commit and a matching
update to this document if its identity or provenance changes.

The long-term preference is to replace a pre-built binary with a source build
only when its source provenance, toolchain inputs, and output compatibility can
be reproduced and verified. Until then, the tracked binary itself is the
versioned release input.

## VLF generations

The retained `vlf.prx` above belongs to the pre-1.0 beta/DC lineage and keeps
its historical filename. Repository directories distinguish generations instead:
`src/vlf_beta/` for the beta/DC ABI and `src/vlf_1/` for the official VLF 1.0
package. The two are not treated as interchangeable binaries.
